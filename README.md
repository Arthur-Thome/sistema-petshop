# Sistema de Gestão para Pet Shop

Sistema web para gerenciamento das principais operações de um pet shop.

## Funcionalidades planejadas

- Cadastro de tutores
- Cadastro de pets
- Upload de fotos dos pets
- Controle de produtos
- Controle de estoque
- Entrada e saída de creche
- Check-in e check-out de hotel
- Controle de banho e tosa
- Gerenciamento de usuários
- Controle de permissões
- Recuperação de senha por e-mail
- Registro de logs e auditoria
- Confirmação para operações críticas
- Dashboard administrativo

## Tecnologias

### Frontend
- React
- Vite
- JavaScript
- HTML
- CSS

### Backend
- Node.js
- Express

### Banco de dados
- PostgreSQL
